# リマインダー機能

VLL25Bot のリマインダー機能を使って、指定した日時にメッセージを自動送信できます。

---

## 基本的な使い方

### リマインダーを登録する

`/remind add` コマンドでリマインダーを登録できます。

```
/remind add message:会議の準備 datetime:明日 14:00
```

**パラメータ**:
- `message` (必須): 送信するメッセージ
- `datetime` (必須): 送信日時
- `channel` (省略可): 送信先チャンネル（省略で現在のチャンネル）

**日時の指定方法**:
- 絶対指定: `2026/01/15 9:00`, `2026-01-15 09:00`
- 相対指定（日本語）: `明日 10:00`, `来週月曜 14:00`, `3日後 15:30`
- 相対指定（時間）: `1時間後`, `30分後`, `1時間30分後`

---

### リマインダーを編集する

登録したリマインダーは2つの方法で編集できます。

#### 方法1: 編集ボタン（モーダル）

リマインダー登録時に表示される「✏️ 編集」ボタンをクリックすると、モーダルが開きます。

- **メッセージ欄**: 変更したい場合のみ入力
- **日時欄**: 変更したい場合のみ入力
- 空欄のまま送信すると、その項目は変更されません

#### 方法2: `/remind modify` コマンド

```
/remind modify id:abc123 message:更新されたメッセージ
/remind modify id:abc123 datetime:明後日 10:00
/remind modify id:abc123 channel:#general message:変更
```

**パラメータ**:
- `id` (必須): リマインダーのID
- `message` (省略可): 新しいメッセージ
- `datetime` (省略可): 新しい日時
- `channel` (省略可): 新しい送信先チャンネル

> **Note**: IDは「📋 IDをコピー」ボタンで簡単にコピーできます

---

### リマインダー一覧を見る

#### 特定のチャンネルのリマインダー

```
/remind list
/remind list channel:#general
```

指定したチャンネル（省略時は現在のチャンネル）のリマインダー一覧を表示します。

**オプション**:
- `channel`: 表示するリマインダーの送信先チャンネル
- `user`: 表示するリマインダーの作成者（省略で全員）

#### 自分のリマインダー全て

```
/remind list_all
```

ギルド内の自分が作成したリマインダーを全て表示します。

---

### リマインダーを削除する

#### 方法1: 削除ボタン

リマインダー登録時に表示される「🗑️ 登録解除」ボタンをクリック。

#### 方法2: `/remind remove` コマンド

```
/remind remove id:abc123
```

---

## ボタンの説明

リマインダーを登録すると、以下の3つのボタンが表示されます：

| ボタン | 機能 |
|--------|------|
| ✏️ 編集 | モーダルを開いて編集 |
| 📋 ID | リマインダーIDを表示（Ephemeral） |
| 🗑️ 登録解除 | リマインダーを削除 |

---

## 権限

- **編集・削除**: 自分が作成したリマインダーのみ
- **一覧表示**: 
  - `/remind list`: チャンネルのリマインダー（全員の）
  - `/remind list user:@ユーザー`: 特定ユーザーのリマインダー
  - `/remind list_all`: 自分のリマインダー全て

---

## Tips

### IDの確認が便利

`/remind modify` や `/remind remove` でIDを入力する際、「📋 ID」ボタンを使うと便利です。

1. 📋 ボタンをクリック
2. コードブロックで表示されたIDをコピー（デスクトップ版では自動的にコピーボタンが表示されます）
3. コマンドに貼り付け

### 日時指定の柔軟性

以下のような指定が可能です：

```
明日 9:00
3日後 14:30
来週月曜 10:00
1時間30分後
2026/12/25 18:00
```

詳細は [日時パーサーの仕様](../src/lib/parser/EBNF.txt) を参照してください。

## よくある質問

**Q: 過去の日時を指定するとどうなりますか？**  
A: エラーメッセージが表示され、リマインダーは登録されません。

**Q: 他の人のリマインダーを編集できますか？**  
A: できません。自分が作成したリマインダーのみ編集・削除できます。

**Q: リマインダーは何件まで登録できますか？**  
A: 現在、特に制限はありません。

**Q: Bot再起動後もリマインダーは維持されますか？**  
A: はい。SQLiteデータベースに保存されているため、Bot再起動後も自動的に復元されます。
