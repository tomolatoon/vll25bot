# その他機能 (Misc)

リマインダー以外の小規模な機能について解説します。

## おみくじ (`/omikuji`)

運勢をランダムで表示するコマンドです。
日替わりで運勢が変わるわけではなく、コマンド実行のたびに抽選を行います。

```
/omikuji
```

### 確率設定

| 運勢 | 絵文字 | 確率 |
| :--- | :---: | :---: |
| 大吉 | 🎊 | 5% |
| 中吉 | 🎉 | 15% |
| 小吉 | 🌸 | 20% |
| 吉 | ✨ | 25% |
| 末吉 | 🍀 | 20% |
| 凶 | 💧 | 14% |
| 大凶 | 🌧️ | 1% |

## 閑話休題 (`/kanwa`)

「閑話休題」と表示します．

```
/kanwa [space](opt) [reasion](opt) [times](opt)
```

- `space`: 間に入れる空白の数 (デフォルト: 5)
- `reason`: 閑話休題の後に続ける理由 (デフォルト: なし)
- `times`: 閑話休題を繰り返す回数 (デフォルト: 1，最大5)

## Ping (`/ping`)

Botの応答速度を確認します。

```
/ping
```

- **Websocket Ping**: Discord Gatewayとの通信遅延
- **API Ping**: メッセージ送信にかかった時間

## Fetch (`/fetch`)

Discordのメッセージリンクから、そのメッセージの内容を転送して表示します。
（引用RTのような機能）

```
/fetch [message_url]
```

- `message_url`: 対象メッセージの URL
