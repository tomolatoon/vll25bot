# リマインダー機能

指定した日時にメッセージを自動送信できます。

## コマンド一覧

| コマンド | 説明 |
| --- | --- |
| `/remind add` | 新しいリマインダーを登録します |
| `/remind modify` | 既存のリマインダーを編集します |
| `/remind cancel` | リマインダーを解除（削除）します |
| `/remind list` | チャンネルのリマインダー一覧を表示します |
| `/remind show` | 指定したリマインダーの詳細を表示します |

---

## 1. リマインダーを登録する (`/remind add`)

指定した日時にメッセージを送信する予約をします。

```
/remind add [message] [datetime] [channel](opt)
```

### パラメータ
- `message` (必須): 通知するメッセージ内容
- `datetime` (必須): 通知する日時
    - **絶対指定**: `2026/01/15 9:00`, `1/15 9:00`
    - **和暦/日本語**: `2026年1月15日 9時`, `明日 9:00`, `来週月曜 10:00`
    - **相対指定**: `1時間後`, `30分後`, `10分後`

### 登録後の画面
登録が完了すると、自分だけに以下の情報が表示されます。
- ✅ 登録完了メッセージ
- **「✏️ 編集」ボタン**: 内容を修正できます（モーダルが開きます）
- **「📋 ID」ボタン**: リマインダーIDを表示します（コピー用）
- **「🗑️ 解除」ボタン**: リマインダーを取り消します

---

## 2. リマインダーを編集する (`/remind modify`)

登録済みのリマインダーの内容や時間を変更します。

```
/remind modify [id] [message](opt) [datetime](opt) [channel](opt)
```

- **IDの取得**: `/remind list` の表示や、登録時の「📋 ID」ボタンから確認できます。
- 変更したい項目だけを指定すればOKです。

---

## 3. リマインダーを解除する (`/remind cancel`)

リマインダーを削除します。

```
/remind cancel [id]
```

- 解除すると、元に戻すことはできません。

---

## 4. リマインダーを確認する (`/remind list`)

現在登録されているリマインダーの一覧を表示します。

```
/remind list [channel](opt) [user](opt) [order](opt)
```

### 機能
- **ページネーション**: `◀️ 前へ` `次へ ▶️` ボタンでページ切り替え
- **ページジャンプ**: `🔢 ページ移動` ボタンで指定ページへジャンプ
- **ソート**: `⬇️ 降順/昇順` ボタンで日時の順序を切り替え
- **再読み込み**: `🔄 更新` ボタンで最新情報を取得
- **アクション**: プルダウンメニューからリマインダーを選択して、詳細確認・編集・削除が可能

---

## 5. リマインダーを表示する (`/remind show`)

登録済みのリマインダーの内容な時間などの詳細情報を表示します。

```
/remind show [id]
```

## 権限と仕様

- **編集・削除権限**:
    - **自分が作成したリマインダー**: 自由に編集・削除可能
    - **他人が作成したリマインダー**: 編集・削除不可（管理者権限があってもBot上では制限されています）
- **通知先**:
    - デフォルトではコマンドを実行したチャンネルに通知されます。
    - `/remind add` の `channel` オプションで変更可能です。
